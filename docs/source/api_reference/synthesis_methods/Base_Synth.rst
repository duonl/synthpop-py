Base synthesis
---------------------------------------
.. note::

    The module for **Base Synthesis** is not intended to directly be used by users for synthetic dataset generation. 
    It is a base class that other methods inherit from, and should be used for creating your own synthesis method.
    See `Example: Create your custom synthesis method <../../examples/custom_synth.html>`__.
