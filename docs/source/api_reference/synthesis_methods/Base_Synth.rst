Base synthesis
---------------------------------------
.. note::

    The **Base Synthesis** module is not intended to be used directly for generating synthetic datasets.
    It provides the base class from which synthesis methods can inherit when implementing
    a custom synthesis method. See `Example: Create your custom synthesis method <../../examples/custom_synth.html>`__.
