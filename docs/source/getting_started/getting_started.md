# Getting Started

Welcome to the Synthpop documentation. This guide will help you install the package, understand the main concepts behind synthetic data generation, and create your first synthetic dataset.

Synthpop is a Python framework for generating synthetic data that can be used for analysis, development, and experimentation while preserving the important statistical characteristics of the original data. 
The goal of this project is to provide users with a flexible and reproducible workflow for creating synthetic datasets.

If you are new to Synthpop, we recommend following the guides in order:

1. **{doc}`installation`** — Install Synthpop.
2. **{doc}`overview`** — Learn about the package structure, workflow, and key concepts.
3. **{doc}`first_synthesis`** — Create your first synthesis in 5 lines of code, and explore the generated output.
