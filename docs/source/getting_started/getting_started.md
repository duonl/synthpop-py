# Getting Started

Welcome to the Synthpop-py documentation. This guide will help you install synthpop-py, learn the basic workflow for synthetic data generation, and create your first synthetic dataset.

Synthpop-py is a Python package for generating synthetic tabular data while preserving important statistical patterns and relationships from the original dataset. It provides a reproducible workflow for generating synthetic records and evaluating the quality of the results.

If you are new to Synthpop-py, we recommend following these guides in order:
1. **{doc}`installation`** — Install Synthpop-py.
2. **{doc}`about synthpop-py <overview>`** — Learn about the synthesis workflow, key concepts, and how Synthpop approaches synthetic data generation.
3. **{doc}`first_synthesis`** — Create your first synthetic dataset and inspect the results.

After completing these steps, explore more advanced examples and workflows in the {doc}`../user_guides/user_guides_index`.

For detailed information about available functions, classes, and parameters, see the {doc}`../api_reference/synthpop`.
