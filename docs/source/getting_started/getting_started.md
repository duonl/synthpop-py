# Getting Started

Welcome to the Synthpop documentation. This guide will help you install the package, understand the main concepts behind synthetic data generation, and create your first synthetic dataset.

Synthpop is a Python framework for generating synthetic data that can be used for analysis, development, and experimentation while preserving the important statistical characteristics of the original data. The goal is to provide a flexible and reproducible workflow for creating high-quality synthetic datasets without exposing sensitive source information.

If you are new to Synthpop, we recommend following the guides in order:

1. **Installation** — Install Synthpop.
2. **Overview** — Learn about the package structure, workflow, and key concepts.
3. **First synthesis** — Run your first synthesis process and explore the generated output.
